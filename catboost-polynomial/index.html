CatBoostClassifier on Polynomial Features

Feature engineering meets gradient boosting on the Palmer Penguins dataset

Introduction

CatBoost is a gradient boosting library with a key strength: it natively handles categorical features without requiring manual encoding. Rather than forcing you to one-hot encode or label-encode categorical columns, CatBoost uses an internal ordered target statistics approach to deal with them directly during training.

Polynomial features expand the numeric input space by adding interaction terms and powers up to a specified degree. With degree=2, a feature x becomes x, x², and pairs of features x, y gain an interaction term x·y. This gives the model richer signal without manual feature crafting — the algorithm can discover non-linear relationships that would otherwise be invisible to a linear boundary.

Feature Engineering

The pipeline is built to keep numeric and categorical columns on separate tracks, then merge them before handing off to CatBoost:

  • Numeric columns: median imputation for missing values, then PolynomialFeatures(degree=2) applied to expand the feature space.
  • Categorical columns: most-frequent imputation only — no encoding needed, as CatBoost's cat_features parameter handles species and sex natively.
  • Both tracks are concatenated back into a single matrix before training.

Model evaluation uses stratified 5-fold cross-validation to ensure each fold preserves the class distribution of the Palmer Penguins target (species: Adelie, Chinstrap, Gentoo).

Results & Notebook

Cross-validation scores across 5 folds: 0.9818, 0.9455, 0.9455, 1.0, 1.0. The model achieves a final held-out test accuracy of 97.1% — a strong result given the compact dataset size (344 samples).

The combination of polynomial feature expansion and CatBoost's native categorical handling eliminates the usual preprocessing boilerplate while still extracting strong predictive signal.
