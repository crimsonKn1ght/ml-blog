CatBoostClassifier on Polynomial Features

Feature engineering meets gradient boosting on the Palmer Penguins dataset

Introduction

CatBoost handles categorical features natively during training, no preprocessing step needed. Pass the column indices via cat_features and it deals with encoding internally using ordered target statistics.

Polynomial features expand the numeric input space by adding interaction terms and powers. With degree=2, a feature x becomes x and x², and two features x, y also get a cross term x·y. The model then picks up on relationships it would miss if only raw columns were passed in.

Feature Engineering

The pipeline keeps numeric and categorical columns on separate tracks, then recombines them before training:

  • Numeric columns: median imputation for missing values, then PolynomialFeatures(degree=2) to expand the feature space.
  • Categorical columns: most-frequent imputation only. CatBoost's cat_features parameter handles species and sex natively, so no encoding is needed.
  • Both are concatenated into a single matrix before being passed to CatBoost.

Model evaluation uses stratified 5-fold cross-validation to preserve class distribution across folds (species: Adelie, Chinstrap, Gentoo).

Results & Notebook

Cross-validation scores across 5 folds: 0.9818, 0.9455, 0.9455, 1.0, 1.0. The model achieves a final held-out test accuracy of 97.1% — a strong result given the compact dataset size (344 samples).

The combination of polynomial feature expansion and CatBoost's native categorical handling eliminates the usual preprocessing boilerplate while still extracting strong predictive signal.
