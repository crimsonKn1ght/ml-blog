Solving CartPole with a Deep Q-Network

Teaching an agent to balance a pole using reinforcement learning and PyTorch

Introduction

CartPole-v1 is a classic reinforcement learning benchmark from OpenAI Gym. A cart sits on a frictionless track, with a pole balanced on top. At each timestep, the agent chooses to push the cart left or right. The environment rewards the agent with +1 for every timestep the pole stays upright. An episode ends when the pole tilts more than 15° from vertical, or when the cart moves outside the track bounds.

The challenge is that the agent receives no explicit instructions — it must learn the correct control policy purely from trial and error, guided only by the reward signal.

The DQN Agent

Deep Q-Networks extend classical Q-learning by approximating the Q-function with a neural network. The architecture used here:

  • Q-Network: Linear(4→128) → ReLU → Linear(128→128) → ReLU → Linear(128→2). Input is the 4-dimensional state vector; output is Q-values for each of the 2 actions.
  • Experience Replay: Transitions (s, a, r, s') are stored in a replay buffer (deque). Mini-batches are sampled randomly to break temporal correlation between updates.
  • Online + Target Networks: Two identical networks are maintained. The online network is updated every step; the target network is synced periodically to stabilize training.
  • Epsilon-Greedy Exploration: ε decays from 1.0 to 0.01 over training, shifting from pure exploration to exploitation as the agent learns.

The Bellman target used for training: r + γ · max Q(s', a') with discount factor γ = 0.99.

Training & Notebook

Training runs for 500 episodes. The rolling 100-episode average reward climbs from roughly 20 at the start to consistently above 200 by the end — surpassing the standard "solved" threshold of 195.

Greedy evaluation across 10 held-out test episodes yields a mean reward of 226.2, demonstrating that the agent has learned a robust balancing policy.
