Decision Tree Classifier from Scratch

Building Gini-based tree splitting in pure NumPy on the Iris dataset

Introduction

A Decision Tree is a supervised learning algorithm that recursively partitions the feature space using a sequence of binary splits. At each internal node, the algorithm selects the feature and threshold that best separates the classes in the current subset of data. This continues until a stopping condition is met, at which point a leaf node is created and assigned the majority class of its samples.

Unlike many black-box models, every prediction a Decision Tree makes follows a traceable, human-readable path of if-else rules. This implementation builds the tree entirely in pure NumPy — no scikit-learn for the tree logic itself.

How It Works

The core of the algorithm is the split selection criterion:

  • Gini Impurity: Measures how often a randomly chosen element from the node would be incorrectly classified. Computed as 1 − Σ(pᵢ²), where pᵢ is the proportion of class i in the node. A pure node (all one class) has Gini = 0.
  • Best split search: For each feature, every unique value is considered as a candidate threshold. The split is evaluated by computing the weighted Gini impurity of the two resulting child nodes. The feature-threshold pair with the lowest weighted Gini is selected.
  • Stopping conditions: Recursion halts when the maximum depth is reached, the node is already pure, or the number of samples falls below min_samples_split.
  • Leaf assignment: Each leaf assigns the majority class among its samples via a simple vote.

Results & Notebook

Tested on the Iris dataset (150 samples, 3 classes) with an 80/20 train-test split and max_depth = 5. The from-scratch implementation achieves 100% test accuracy — matching what scikit-learn's DecisionTreeClassifier produces on the same split.

The Iris dataset is linearly separable in some projections, making it an ideal testbed for verifying that the splitting logic and Gini computation are correct before moving to harder problems.
