Time-Series Forecasting with RNNs

Predicting daily climate data using sequence modeling

What is a Time-Series RNN?

A Recurrent Neural Network (RNN) is a type of neural network specifically designed to recognize patterns in sequences of data. Unlike standard machine learning models that process each data point independently, an RNN has an internal "memory."

As it processes a sequence, it passes information from previous steps forward to the current step. This makes it highly effective for time-series forecasting, where the past (like the weather over the last week) heavily influences the future (tomorrow's weather).

About This Project

This project applies an RNN to forecast climate data using the Daily Delhi Climate dataset. The primary goal is to predict the next day's mean temperature (meantemp).

To do this, we use a sliding-window approach. The model doesn't just look at today's weather to predict tomorrow's; it looks at a rolling window of recent days. The pipeline involves:

  • Extracting temporal features from raw date data.
  • Normalizing features with Min-Max scaling.
  • Formatting the data into sequential sliding-window blocks.
  • Training a vanilla RNN to learn the temporal patterns and output a final prediction.
